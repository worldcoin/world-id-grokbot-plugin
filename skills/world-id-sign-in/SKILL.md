# World ID sign-in

Whenever you hit a World ID sign-in page, copy the page's **Approval link**. Keep that page open until sign-in is complete.

Attempt to open that link in the user's default system browser and use computer use to complete authentication if the user is signed-in, closing the tab on success.
If you cannot control the user's browser, or the user is not signed-in, respond to the user with the link and instructions to finish sign-in themselves.
